A timer for the work in front of you

Readable interval workouts, wherever you train.

Ocho is a focused Android workout timer that stays clear across the room and keeps the clock honest when the screen goes dark.

Two ways to get Ocho

Choose the channel that fits.

Google Play

The Play variant is built without the GitHub self-updater and without package-install permission. The listing will be linked here when it exists.

GitHub Releases

The GitHub variant is a manually installed APK and retains its GitHub release updater. It may ask for permission to install unknown apps.

Open source

Built in public, licensed for freedom.

Ocho's source and both distribution build configurations are public. The project is GPLv3; fonts, icons, and libraries keep their own notices.
